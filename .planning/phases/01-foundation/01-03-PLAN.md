## STRIDE Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Logout action | mitigate | Logout is a POST form with @csrf (never a GET link), preventing CSRF logout |
| T-03-02 | Information Disclosure | Layout separation | mitigate | Separate admin vs client shells prevent admin nav/links leaking into the client portal (project decision) |
| T-03-03 | Spoofing | Inline SVG icons | accept | Icons are static inline SVG with aria-hidden; no remote/script content, no injection surface |

**Assets:** Navigation surface, session (via logout), brand chrome.
**Attack vectors:** CSRF logout, cross-role nav leakage.
**Mitigations:** POST+CSRF logout, strict admin/client layout separation, static inline icons.
**Residual risks:** These are presentation shells only — actual route authorization is enforced by Plan 04 middleware/gates; verify no admin-only path is reachable from the client shell.
</threat_model>

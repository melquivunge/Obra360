  <how-to-verify>
Open the app (URL reported in Task 1) and verify each, using the seeded credentials:

1. LOGIN LOOK (UX/D-14): Visit /login. Confirm a centered white card on a navy background, "Obra360" + building icon, "Acesse sua conta" subtitle, "E-mail"/"Senha" labels, "Esqueci a senha" link, green "Entrar" button. All Portuguese.
2. BAD CREDENTIALS (AUTH): Submit a wrong password. Confirm the message "E-mail ou senha incorretos." appears.
3. INACTIVE BLOCK (AUTH-04): Log in as the inactive user with the correct password. Confirm you are NOT logged in and see "Sua conta está inativa. Entre em contato com o administrador."
4. ROLE REDIRECTS (AUTH-01): Log in as admin -> lands on /admin dashboard with the full navy sidebar. Log out. Log in as the client -> lands on /portal with the minimal client top nav (5 items: Minhas Obras, Documentos, Mensagens, Meu Perfil, Sair).
5. ADMIN SIDEBAR (UX-02): Confirm all 11 items appear in Portuguese (Dashboard, Clientes, Obras, Fases, Fotos, Despesas, Documentos, Relatórios, Usuários, Configurações, Sair) with the active item highlighted.
6. RESPONSIVENESS (UX-01): Shrink the browser to mobile width. Admin: the sidebar collapses to a hamburger that opens a drawer. Client: the nav collapses to a dropdown.
7. USER CRUD (USR-01..05): As admin, go to Usuários. Create a new user (all four roles available in the Perfil select), see it in the paginated list with role + status badges. Edit it and change the role. Toggle Desativar/Ativar. Click Excluir -> confirm the "Tem certeza..." dialog appears and the user disappears from the list.
8. ACCESS CONTROL (SEC-01): While logged in as the client, manually visit /usuarios. Confirm a 403.
9. PASSWORD RESET (AUTH-03): From /login click "Esqueci a senha", submit an email, confirm "Link enviado! Verifique seu e-mail." (in local/log mail, the reset link is written to the log).

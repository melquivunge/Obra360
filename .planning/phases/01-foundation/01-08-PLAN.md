## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated browser → admin navigation | Role-gated links and account identity are rendered server-side |
| authenticated browser → user mutation forms | Activate/deactivate/delete operations cross a state-changing POST/DELETE boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-0108-01 | Elevation of privilege | Admin sidebar and user-management pages | high | mitigate | Preserve all existing route middleware and authorization; visual grouping must not introduce routes or bypass controller/policy checks. Tests must continue to assert non-admin denial. |
| T-0108-02 | Tampering | Toggle/delete forms | high | mitigate | Preserve POST/DELETE methods, `@csrf`, model-bound route parameters, and confirmation for deletion. Never convert mutations to GET links. |
| T-0108-03 | Information disclosure / XSS | User name and initials in top bar/table | medium | mitigate | Keep Blade escaped `{{ }}` output; introduce no `{!! !!}` rendering or user-derived HTML attributes. |
| T-0108-04 | Denial of service | Responsive table/layout | low | accept | Styling changes add no server work or unbounded client loop; no mitigation required. |
</threat_model>
